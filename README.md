# 🧠 MemFlow — умные карточки по кривой забывания

Один файл-приложение: аналог AnkiDroid с алгоритмом **FSRS-17**. Работает офлайн, без сервера, без сборки.

**🔗 Открыть: [uwsqq.github.io/memflow](https://uwsqq.github.io/memflow/)**

## Что внутри
- **FSRS-17** (канон FSRS-4.5) + онлайн-калибровка Platt (SGD) + sleep-aware интервалы
- Свайпы тиндер-стиль, турбо-режим, интерливинг, cloze, ввод ответа с посимвольным diff
- Библиотека: все предметы **ОГЭ-2026** + классы 5–11 + языки (ES/ZH/HI)
- Импорт: Anki `.apkg` (с расписаниями), CSV с датами, txt, json, drag&drop
- Кнопка «🅰️ Колоды Anki» — поиск по AnkiWeb
- Игры: дуэль памяти с ботом, пузырьки, «Найди пару»
- Статистика: кривая силы памяти, heatmap года, слабые места, PNG-постер
- 5 языков интерфейса, темы, PWA

## Колоды сообщества

Скачай `index.html` и открой в браузере. Всё работает без интернета.
